The corresponding source attachment contains the exact FFmpeg, x264, zimg,
dav1d, zlib and selected toolchain source archives, offline recipe, final
configuration, zimg patch, upstream notices and GCC runtime exception.
Build instructions are included in that attachment. Normal application use
does not require downloading source or installing build tools.

The four external media libraries are rebuilt into an isolated prefix.
The build disables network access and optional-library autodetection.
HTTPS uses Windows Schannel. Normal media output uses stream copy;
only user-selected compatibility mode permits H.264/AAC conversion.
